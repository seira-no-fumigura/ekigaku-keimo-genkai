# 易学啓蒙（諺解大成）（えきがく けいもう げんかい たいせい）

星羅の文庫（せいらのふみぐら）の一作品です。著作権の保護期間が満了した本から起こした本文を、誰でも読み・使い・直せるように置いています。

易学啓蒙の国字解。榊原篁洲の『易学啓蒙諺解大成』で、序・本図書・原卦画・明蓍策・考変占を、原文に国字の解を付けて収める。明治 44 年（1911 年）に早稲田大学出版部が『漢籍国字解全書』第 3 巻に収めたもの。OCR の柱から付けた見出しが付く。

## 底本

- [漢籍国字解全書 : 先哲遺著](https://dl.ndl.go.jp/pid/898776)（早稲田大学編輯部 編・早稲田大学出版部・1911年）。国立国会図書館の全文テキスト（OCR）のまま

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
